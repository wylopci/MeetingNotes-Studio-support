MeetingNotes Studio 隱私權政策

最後更新：2026 年 8 月

本政策適用範圍

本政策說明 MeetingNotes Studio 如何處理音檔、逐字稿、摘要、設定與購買資訊。

本機與 iCloud 資料

音檔、逐字稿與摘要檔只會儲存在使用者選擇的 Mac 或 iCloud 資料夾。離線語音辨識不會上傳音檔。

線上 AI 摘要

只有使用者主動按下「AI 會議摘要」時，逐字稿文字才會送至使用者選擇的 OpenAI、Anthropic 或 Google 服務。各服務依其自身條款與隱私政策處理資料。

API Key 與購買資訊

API Key 儲存在 macOS 鑰匙圈，不會寫入會議檔案、逐字稿、摘要或本網站。App Store 購買交易由 Apple 處理；本 App 不會取得完整付款資訊。

YouTube 聽寫

YouTube 聽寫不下載影片、音檔或字幕；功能會在使用者授權後擷取正在播放的系統音訊，並在處理完成後刪除暫存資料。

使用者控制與聯絡

使用者可刪除會議檔案、逐字稿與摘要。隱私權問題可透過支援頁聯絡我們：GitHub Issues。
