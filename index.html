快速開始

  1. 在設定中下載需要的離線模型。
  2. 將 M4A、MP3、MP4 或其他支援的音訊／影片檔匯入，或開始新錄音。
  3. 等待逐字稿完成；需要時可按「重新辨識」。
  4. 確認逐字稿後，手動按「轉 AI 會議摘要」並選擇摘要強度。
  5. 從逐字稿或摘要分別匯出 DOCX、PDF、TXT 或 Google Docs 匯入檔。

隱私權與資料處理

音檔、逐字稿與摘要檔預設只儲存在你的 Mac／iCloud 指定資料夾。離線語音辨識不會上傳音檔。

只有在你主動按下「轉 AI 會議摘要」時，逐字稿文字才會送到你設定的線上模型服務商。API Key 儲存在 macOS 鑰匙圈，不會寫入會議檔案或網站。

模型與授權

離線模型由使用者在 App 內主動下載；下載前請閱讀各模型的官方授權與使用限制。

  • Breeze-ASR-26：中文／臺語離線語音辨識，請依 官方模型頁 授權使用。
  • Whisper MLX：粵語、英文、日文、韓文離線語音辨識，請依 MLX 與模型來源授權使用。
  • 線上摘要服務（OpenAI、Anthropic、Google）受各服務商條款與隱私政策規範。

常見問題

辨識卡住怎麼辦？

確認模型已完成下載、磁碟空間足夠，並先用短音檔測試；必要時按取消後重新辨識。

YouTube 聽寫需要什麼？

功能會在預設瀏覽器播放影片並擷取系統音訊，不下載影片或字幕；請先在 macOS 隱私權與安全性中允許螢幕與系統音訊擷取。

如何取得協助？

請前往 GitHub Issues，提供 macOS 版本、App 版本、使用的模型與錯誤訊息；請勿上傳含個資的音檔或逐字稿。

系統需求

MacMeetingNotes 目前以 Apple Silicon Mac（M1、M2、M3、M4）為支援目標，需 macOS 14 或以上版本。離線模型下載與轉換可能需要額外磁碟空間。
